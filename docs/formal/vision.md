# Vision

**doc1st, designed by doc1st.**

*Edit files. Commit intent. Let agents reconcile.*

doc1st explores replacing chat as the **primary interface for sustained agent-driven project work** with familiar artifact editing and Git history. Chat remains available for exploration and help; the lasting shared state is in the project, not buried in a conversational transcript.

A human can edit any diffable artifact, including code originally generated by an agent. The human commit groups those edits into an intentional change. The message may supply an immediate command; the diff and repository give context and hints about the desired longer-term state. An existing agent coordinates toward that state, possibly in partial increments, while surfacing genuinely unresolved decisions in context.

The goal is a portable **method/protocol and, eventually, a lightweight optional client**, not a replacement IDE, Git implementation, or foundation model agent. The project should continue to work with ordinary IDEs, Codex App/CLI, other agents, and standard Git when doc1st is not installed or enabled.

This repository is deliberately used to build and evolve the method itself; see `self-evolution.md`.
