# Decision 0006 — Brand expression

**Status:** Accepted in project design discussion

## Decision

Use lowercase **doc1st** as the project and protocol name. The primary brand line is:

> **doc1st, designed by doc1st.**

The explanatory subtitle is:

> *Edit files. Commit intent. Let agents reconcile.*

## Rationale

The headline emphasizes the recursive ambition to develop the project using its own method. The subtitle states the concrete human interaction and agent responsibility without asserting that a standalone client is already built.

The brand language may evolve through reviewable human intent and subsequent agent changes, subject to the project's general self-evolution guardrails.
