# Decisions

Capture **accepted** project choices, the rationale, and alternatives. These documents explain why active requirements are as they are; formal docs/protocol express what currently governs. An agent-authored proposal is not automatically accepted. Mark superseded decisions clearly instead of pretending they never existed.

Recommended fields: Status, Decision, Context, Rationale, Consequences, and Supersedes (if any). Do not invent human approval: recorded decisions in this repository are grounded in explicit choices made during the project's design discussion.
