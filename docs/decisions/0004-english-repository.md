# Decision 0004 — English repository, user-language conversation

**Status:** Accepted direction

## Decision

All project artifacts use **English** (including filenames, prose, code comments and commit messages), while conversations with a user may use the **user's language**. Always spell the product **`doc1st`** lowercase.

## Rationale

Consistent durable project material helps multi-agent navigation and collaboration without forcing a user to converse in English. Historical evidence may retain its original language only when explicitly preserved for evidence, not as active project content.
