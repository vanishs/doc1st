# Decision 0005 — Archaeology is explicitly opt-in

**Status:** Accepted direction

## Decision

Use `archaeology/` for non-authoritative original traces and historical investigation. Agents must **not** read/search it during ordinary work or doc1st cycles. Only a **human's explicit request for archaeology** (or for named material in the directory) enables access.

## Rationale

Old brainstorms and raw logs can contaminate current requirements. Retain a path to history without letting historical artifacts override current formal knowledge and decisions.
