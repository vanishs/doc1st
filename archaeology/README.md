# Archaeology — explicitly opt-in historical evidence

**Access policy:** **Do not read, search, cite, summarize, or draw conclusions from anything under `archaeology/` during normal project work, normal research, or ordinary doc1st cycles.** Access only when the **human explicitly asks for archaeology / historical investigation**, or directly asks to inspect specific material in this directory.

This directory is a quarantine for historic discussion traces, raw experiment artifacts, and legacy prototypes that may contain superseded or contradictory ideas. None of its contents is a current specification, accepted decision, or working requirement. Use `docs/formal/`, `protocol/`, `docs/decisions/`, and active experiments instead.

When archaeology is requested, report what the original historical material said **as historical evidence**, separate it from current rules, avoid copying secrets or personal metadata, and suggest explicit changes if the findings should become active knowledge. Never silently promote archaeological claims.
