# Experiments and validation

This directory stores **interpreted experimental evidence**: hypotheses, procedure, outcomes, failures, uncertainty, and follow-ups. It is not the archaeology area; raw unfiltered historical traces belong in `../archaeology/` only when explicitly imported.

- [`codex-v0.1/README.md`](codex-v0.1/README.md): manual Codex bootstrap experiment and reproduction notes.
- [`codex-v0.1/timeline.md`](codex-v0.1/timeline.md): seven observed cycles and checkpoint identifiers.
- [`codex-v0.1/findings.md`](codex-v0.1/findings.md): conclusions, limits, and suggested next experiments.
- [`codex-bootstrap-minimal/README.md`](codex-bootstrap-minimal/README.md): minimal message-only change, blocked invocation, successful checkpoint, and no-new-input replay.
- [`codex-bootstrap-boundaries/README.md`](codex-bootstrap-boundaries/README.md): small dirty-worktree, third-party authorization, and marker-deletion trials with independent Git/file verification.
- [`git-origin-metadata/README.md`](git-origin-metadata/README.md): isolated Git metadata trial distinguishing origin labels from producer identity and human authorization.
- [`bootstrap-observations.md`](bootstrap-observations.md): cross-trial synthesis of cycle outcomes, verification, authorization, attention markers, and experimental limits.

Reports from the experimental agent about test passes are **reported results** unless independently rerun and captured here. Do not overclaim correctness across platforms or across agent tools.
